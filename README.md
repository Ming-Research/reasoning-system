# Reasoning

A logical derivation system for planning and designing a project rigorously: a project's axioms, the facts its
derivations take as given, and the decisions derived from them, kept coherent as they change.

- `constitution.md`: the constitution of the system, what it is responsible for and what it is not.
- `rules/reading.md`: for everyone whose work rests on a project's reasoning.
- `rules/writing.md`: for those who derive and change a project's records; it also gives how a project's `reasoning/`
  directory is laid out.
- `rules/dcr.md`: the design coherence review, which checks that the records stay coherent.
- `rules/extension-work.md`: an extension, keeping a project's work in line with its derivations.
